# Basic POS System

This is a four-page CodeIgniter 4 website using static PHP arrays.

## Pages

- `/`
- `/about`
- `/customers`
- `/users`

## Run with XAMPP

1. Place the `ciapp` folder in `C:\xampp\htdocs`.
2. Start Apache in XAMPP.
3. Open `http://localhost/ciapp/public/`.

PHP 8.2 or newer is required.

No database is used in this activity.
